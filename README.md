# Clock Frequency Divider Example

Contains the design and test bench for two different dividers
- Divide by 5 frequency divider
- Configurable divide by N frequency divider

Running the Makefile will run the testbench for the divide by N frequency divider. The tesbench instatiates module for div3, div4, and div5. <br>

Icarus Verilog and GTKWave are used for compilation and waveform viewing.
